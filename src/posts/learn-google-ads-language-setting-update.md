Google has removed the campaign-level language setting from Search campaigns and from the Search portion of Performance Max. Advertisers used to choose the languages they wanted to reach, and Google limited the campaign to users it believed understood them. That manual control is gone.

Google announced the change on 14 August 2026. It was first scheduled for the end of 2025, so it arrived about nine months late. The setting is now missing from accounts, and advertisers have reported it disappearing from campaign settings from early November onward.

## What replaces it

Google now decides who sees a Search ad using two things: the language the ad and its landing page are written in, and its own understanding of the languages each user can read. That second signal draws on the search query, browser settings and search history.

In practice, the language of your ads and landing pages now does the job the setting used to do. An English ad on an English page is more likely to reach English readers. A Spanish ad on a Spanish page is more likely to reach Spanish readers. Bilingual users may see either version, depending on what Google judges they understand.

## What stays the same

- Existing campaigns keep running. Google says you do not need to restructure them.
- Language criteria already set on a campaign stay in place, but they no longer affect Search targeting. You can remove them if you want a tidier account.
- Reporting is unchanged, so historic performance data is not affected.
- Performance Max still uses language settings for YouTube, Display, Discover and Gmail. Only the Search Network part has changed.

## What to check now

**Ad language.** Make sure each ad is written in the language you want to reach. A translated headline inside an English campaign sends a mixed signal. Write each language version properly, with its own descriptions and calls to action.

**Landing pages.** Send each language to a matching page, including the form, the phone instructions and any confirmation message. A Spanish ad that lands on an English page will convert poorly, and it weakens the signal Google uses to match users.

**Campaign structure.** Separate campaigns by language where the results matter to you. This is not required, but it lets you see which language is producing sales or leads, and set budgets accordingly.

**Keywords.** Review keyword lists for language mismatches. A keyword in one language inside a campaign built for another can attract searches you did not intend.

**Scripts and integrations.** If scripts or API tools change language criteria on Search campaigns, they will now return an error. Remove or disable those steps before they fail in a scheduled run.

**Search terms.** Check the search terms report for the first few weeks after the change. Look for queries in languages you do not serve, and add negative keywords where needed.

## The bottom line

The language setting is gone from Search, but the need to reach the right language has not. Your ads and landing pages now carry that job. Write each language properly, send it to a matching page, and track results by language so you can see what is working.
